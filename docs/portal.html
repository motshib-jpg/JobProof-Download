Privacy & trust • الخصوصية والثقة

The payload is carried in the URL fragment after # and verified in this browser using ECDSA P-256. Browsers do not send the fragment in the HTTP request to GitHub Pages. Anyone who receives the complete link can still view the portal, so share it only with the intended client. The business identity is device-signed; external registry verification requires a server-backed trust layer.
